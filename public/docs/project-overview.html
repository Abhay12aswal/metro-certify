1. Project Overview & Mission

MetroCertify is an authentic Indian e-Governance compliance platform built for the Department of Consumer Affairs (DCA) in collaboration with CSIR - National Physical Laboratory (NPL India) and the 5 Regional Reference Standard Laboratories (RRSLs).

The platform completely automates and digitizes the statutory model approval and pattern testing lifecycle for Non-Automatic Weighing Instruments (NAWI)—ranging from high-precision laboratory micro-balances ($e = 0.001\text{ g}$) to retail trade scales and heavy 100-tonne truck weighbridges. It strictly implements the international standards OIML Recommendation R 76-1:2006, OIML R 76-2:2007, and the Legal Metrology Act, 2009 (Eighth Schedule).

2. Problem Statement: Traditional vs. MetroCertify

Historically, testing officers recorded observations on manual paper logbooks or scattered Excel sheets. Field audits revealed that 14.8% of manual test sheets contained arithmetic discrepancies in turning-point interpolations, zero tare corrections ($E_0$), or Maximum Permissible Error (MPE) thresholds.

3. Deterministic OIML R-76 Mathematical Engine

The platform's calculation engine removes human estimation by executing exact metrological formulas defined in OIML R 76-1:2006 Clause A.4.4.3:

1. Turning-Point Indication ($P$): Determines the true analog indication before scale rounding.
P = I + 0.5d - ΔL
Where $I$ is displayed indication, $d$ is scale division, and $\Delta L$ is added fractional load until indication switches to $I + d$.
2. True Error ($E$) and Corrected Error ($E_c$):
E = P - L
E_c = E - E_0 (where E_0 is the error calculated at zero/tare load)
3. Dynamic Maximum Permissible Error (MPE) Verification:

Evaluates $|E_c| \le |\text{MPE}|$ against dynamic statutory limits based on scale accuracy class (Class I, II, III, IIII) and load divisions ($m/e$).

Class Tier 1: ±0.5e Tier 2: ±1.0e Tier 3: ±1.5e

4. System Features & Module Architecture

A. Public Indian e-Governance Portal

Designed strictly under GIGW 3.0 guidelines:

  • National Identity: State Emblem of India, Department of Consumer Affairs bilingual title, and National Tricolor accent ribbon.
  • Accessibility Controls: Live font resizer ($A-, A, A+$), WCAG AAA High-Contrast mode, and bilingual (English / हिंदी) switcher.
  • Interactive 5-Step Process Carousel: Guides users through Metadata → Environment → Load Steps → Influence Factors → Approval.
  • National Testing Network Map: Interactive SVG India Map pinpointing CSIR-NPL New Delhi and all 5 RRSL facilities (Faridabad, Ahmedabad, Varanasi, Bhubaneswar, Bengaluru) with clickable inspection profiles.

B. High-Density Laboratory Evaluation Workspace

  • Real-time Compliance Banner: Prominent solid Green PASS or solid Red FAIL banner showing peak error, tested points, and legal MPE thresholds.
  • Weighing Performance Matrix: Interactive data table handling ascending and descending load cycles with a 1-click "Generate Standard Steps" feature.
  • Additional Statutory Tests: Dedicated modules for Eccentricity (Corner Load - Clause 3.6.2), Repeatability (Clause 3.6.1), and Tilt Stability (Clause 3.9.1.1).
  • Embedded OIML R 76-2 Certificate: Print-optimized certificate preview with dual officer sign-offs and client-side scannable cryptographic QR verification stamp.
  • Action Sidebar & Presets: Instant 1-click loading of real test scenarios: Class III 15kg Retail Scale (PASS), Class II 600g Analytical Balance (PASS), and Class III 30kg Scale with Defect (FAIL).
